# Excel VBA Toolkit

A collection of Excel VBA tools for common business automation tasks. Each tool is self-contained and designed for easy deployment in a standard Excel environment.

## Tools

### DataEntryForm
A UserForm-based data entry interface that writes validated input to a structured Excel sheet. Includes required field validation, auto-incrementing ID, and status tracking.

### InvoiceGenerator
Generates formatted invoice workbooks from a customer and line-item data sheet. Outputs a print-ready invoice with automatic calculations.

### ReportConsolidator
Consolidates data from multiple worksheets into a single summary report with totals and basic analytics.

## Requirements
- Microsoft Excel with macros enabled (.xlsm)
- Developer tab enabled in Excel ribbon

## Usage
Each tool folder contains the `.xlsm` workbook and exported `.bas` source files for review.
